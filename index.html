Показательные неравенства

Справочные сведения

При решении показательных неравенств пользуются следующими свойствами показательной функции:

  1. если \(a > 1\), то неравенство \(a^{x_1} > a^{x_2}\) справедливо тогда и только тогда, когда \(x_1 > x_2\);
  2. если \(0 < a < 1\), то неравенство \(a^{x_1} > a^{x_2}\) справедливо тогда и только тогда, когда \(x_1 < x_2\).
1. \(\left(\frac{2}{3}\right)^x > 1\frac{1}{2}\)
Правильный ответ: x ∈ (-∞; -1)
2. \(9^{2x} \le \frac{1}{3}\)
Правильный ответ: x ∈ (-∞; -1/4]
3. \(\left(\frac{1}{7}\right)^{x^2 - 9} \le 1\)
Правильный ответ: x ∈ (-∞; -3] ∪ [3; +∞)
4. \(4^x + 2^{x+1} - 80 < 0\)
Правильный ответ: x ∈ (-∞; 3)
5. \(\left(\frac{1}{3}\right)^{\frac{1}{x}} < \frac{1}{27}\)
Правильный ответ: x ∈ (0; 1/3)
